# BlogBash![Build Status](https://img.shields.io/badge/build-passing-brightgreen)![License](https://img.shields.io/badge/license-MIT-blue)

A **production‑ready** Bash blog platform that reads Markdown posts, converts them to static HTML with **Pandoc**, and serves them via a lightweight HTTP server. 
Designed with modern Bash best practices: strict mode, modular architecture, logging, error handling, and tests.

## Features
- 📄 **Markdown → HTML** conversion using Pandoc.
- 🗂️ Automatic index generation.
- ⚙️ Configurable via `.env` (blog directory, server port, etc.).
- 🪵 Structured logging (`INFO`, `DEBUG`, `ERROR`).
- 🧪 Unit‑style test suite written in Bash.
- 🚀 Simple `python -m http.server` based preview server.

---

## Prerequisites
| Tool | Minimum Version |
|------|-----------------|
| `bash` | 4.4+ |
| `pandoc` | 2.0+ |
| `python3` | 3.6+ (only for the preview server) |

All dependencies are listed in `requirements.txt`.
